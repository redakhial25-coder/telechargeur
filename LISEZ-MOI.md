# Téléchargeur de vidéos (Android)

Télécharge les vidéos depuis un lien Facebook, TikTok, Instagram ou YouTube.

## Obtenir l'APK (gratuit, avec GitHub)

1. Créez un compte gratuit sur https://github.com
2. Créez un nouveau dépôt (bouton **New**) appelé `telechargeur`.
3. Cliquez sur **uploading an existing file** et déposez **tout le contenu** de ce dossier
   (y compris le dossier `.github`). Cliquez sur **Commit changes**.
4. Attendez environ 5 minutes (onglet **Actions**, le rond devient vert ✔).
5. Allez dans **Releases** (à droite de la page du dépôt) et téléchargez :
   - `Telechargeur-arm64.apk` → pour la plupart des téléphones récents
   - `Telechargeur-universel.apk` → si l'autre ne s'installe pas

## Utilisation

- Ouvrez l'application, collez le lien, appuyez sur **TÉLÉCHARGER**.
- Ou bien, dans TikTok / YouTube / Instagram / Facebook : **Partager** → **Téléchargeur**.
- Vidéos : dossier `Films/Telechargeur` (visible dans la galerie). MP3 : `Musique/Telechargeur`.
